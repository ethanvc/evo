## 如何应对指标序列爆炸的问题？
指标序列爆炸的原因只有一个：标签值包含基数特别大的值。
在实际业务中，表现为：
- http client端、server端，路径包含参数。
- 上报 error message，包含参数。
- 上报了分片db和表的数字部分。
- 上报了client的 ip。
- 上报了入参中的值，没有做校验。

### 前置处理
- 使用xobs包，在编码时规避这个问题。

### 后置处理
对于http路径，做按需转义配置，逻辑为：
1. 根据配置对路径做pattern匹配，匹配则上报pattern。可以使用httpmux包做转义操作。
2. 默认直接上报path部分，出问题了加配置下发，走逻辑1。

对于error msg等：使用扩展的基数树匹配出模式串进行上报。
