# event（事件）
对于一个全新的系统，可以在编码的时候，确定事件的级别和内容，对于偶尔的级别错误，可以通过屏蔽告警后续通过代码修正。

# 如何解决维度爆炸的问题？
前置：
- 对于path路径，上报模式串，而不是原始的path。比如gin.Context.FullPath().
- 其它场景，注意不要上报维度太大的参数。
- 使用obs.Error，强制分离event和msg，避免将msg上报到监控系统。

后置：
- 使用patternmux将维度很大的字符串映射成维度小的模式串。建议尽量采用第一种。

# 如何解决事件级别上报错误的问题？
- 错误码编码级别信息（INFO、ERR）。
- 通过API+事件配置进行纠错。同时要记得不断将规则沉淀到代码，删除转移，不然太多了。

## 错误
1. 错误均使用xobs.Error表示。
2. 在领域边界处将error转换成xobs.Error。
